Square8 HAKUBA RETREAT — Guide Site
====================================

UNPLAN Village Hakuba ガイドサイトをベースに、姉妹施設 Square8 HAKUBA RETREAT 向けに
構築したトラベルガイドサイトです。

📄 ページ構成 (7ページ / JP・EN):
  index.html            - Welcome (トップ / JP・EN 言語切替)
  hakuba.html           - 白馬ローカルガイド (日本語)
  hakuba-en.html        - Explore Hakuba (English)
  stay.html             - 宿泊ガイド (日本語)
  stay-en.html          - Stay Guide (English)
  green-season.html     - グリーンシーズン 90スポット集 (日本語)
  green-season-en.html  - Green Season Guide (English)
